# network-checker

IT Support diagnostic tool built entirely on Android phone (Termux) in Botshabelo.

**What it does:**
- Validates if an IP address is valid (IPv4)
- Checks if a host is reachable on port 53 (DNS)
- Useful for troubleshooting DNS / Entra ID / Azure connectivity issues

**How to run:**
```bash
python network_checker.py
